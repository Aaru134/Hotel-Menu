# 🍽️ Hotel Menu App

A simple and responsive Hotel Menu web application built using HTML, CSS, and JavaScript. This project allows users to view a categorized menu with filter functionality.

## 🧾 Features

- 🗂️ Category-based filtering (Breakfast, Lunch, Shakes, etc.)
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- 🧠 Beginner-friendly JavaScript logic
